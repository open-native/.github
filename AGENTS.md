# AGENTS.md

Guidance for AI coding agents working in this repository.

## What this repo is

Public files GitHub reads for the `open-native` organization: the profile and the issue forms. Settings, repositories, labels and projects live in the private `platform-github` repo.

## Rules

- This repo is public: no internal names, addresses, hostnames or anything not meant for the internet.
- One issue form per issue type in `.github/ISSUE_TEMPLATE/`; the `description` of each field says how to fill it, for people and agents alike.
