# .github

Public files GitHub reads for the whole `open-native` organization:

- `profile/README.md`: the organization profile.
- `.github/ISSUE_TEMPLATE/`: the issue forms, one per issue type, used by every repository without its own.
- `.github/pull_request_template.md`: the pull request template. The issue is referenced with `Refs`, not `Closes`: merging deploys, and the issue closes only after the deploy is validated.

The organization's settings, repositories, labels, issue types and project are managed in the private `platform-github` repo. This repo is public: nothing private goes in it.
